# Provider workflow catalog

Load only the workflow relevant to the current request.

- [onetrust-consent-preferences](../../onetrust-consent-preferences/WORKFLOW.md): Consent and preference management on OneTrust: collection points, purposes, preference centres, data subjects and their profiles, consent receipts and transactions, linked identities, custom preferences and merge requests. Use when the agent must record or read a consent, look up a data subject's purposes, withdraw consent, or administer purposes and preference centres. Do NOT use for cookie banners (onetrust-cookie-consent) or privacy requests (onetrust-dsar-incident-response).
- [onetrust-cookie-consent](../../onetrust-cookie-consent/WORKFLOW.md): Cookie and consent-banner operations on OneTrust: scan domains and mobile apps, read and categorize discovered cookies, manage geolocation rule groups, templates and branding, publish consent scripts, and read consent-management-platform vendors and interfaces. Use when the agent must launch or check a scan, categorize cookies in bulk, or publish a banner script. Do NOT use for consent receipts and preferences (onetrust-consent-preferences) or assessments (onetrust-privacy-assessments).
- [onetrust-data-mapping](../../onetrust-data-mapping/WORKFLOW.md): Maintain the OneTrust data map: inventories of assets, vendors, legal entities and processing activities, their relations and hierarchy, the data categories, elements and subjects, the glossary and data catalog, and data-discovery scans with their workers. Use when the agent must enumerate or edit inventory records, link them, classify personal data, or run a discovery scan. Do NOT use for assessments over those records (onetrust-privacy-assessments) or cookie scans (onetrust-cookie-consent).
- [onetrust-dsar-incident-response](../../onetrust-dsar-incident-response/WORKFLOW.md): Handle privacy requests and incidents on OneTrust: search and read data-subject requests, verify the requester, run sub-tasks and discovery updates, move requests through stages with resolutions, issue deletion certificates, and log, search, stage and link privacy incidents to inventory. Use when the agent must work a request to closure or record and progress a breach or incident. Do NOT use for consent receipts (onetrust-consent-preferences) or assessments (onetrust-privacy-assessments).
- [onetrust-governance-content](../../onetrust-governance-content/WORKFLOW.md): Governance content on OneTrust: policies and their versions, privacy notices, awareness-training courses and enrollments, ESG disclosures and emission factors, documents and attachments, tasks, and custom objects with their types, links and models. Use when the agent must publish or version a policy, read a notice, track training, read ESG data, fetch a document, or work with custom objects. Do NOT use for assessments (onetrust-privacy-assessments) or users and access (onetrust-platform-administration).
- [onetrust-platform-administration](../../onetrust-platform-administration/WORKFLOW.md): Administer the OneTrust tenant: organizations, users, user groups and access levels, SCIM user and group provisioning, integration workflows, bulk export jobs, and a raw request tool for endpoints without a typed tool. Use when the agent must manage who can do what, provision users, import or export a workflow, or export tenant data. Do NOT use for privacy content (the other onetrust skills).
- [onetrust-privacy-assessments](../../onetrust-privacy-assessments/WORKFLOW.md): Run privacy, risk and AI-governance assessments on OneTrust: list and read assessments, launch from a template, assign respondents, submit, review, approve, reopen and reassess, and manage templates and AI-governance records. Use when the agent must triage in-flight assessments, start a PIA/DPIA, record responses, or close one with a result. Do NOT use for cookie scans (onetrust-cookie-consent), the data inventory (onetrust-data-mapping) or vendor risk (onetrust-risk-compliance).
- [onetrust-risk-compliance](../../onetrust-risk-compliance/WORKFLOW.md): Risk, vendor and compliance operations on OneTrust: IT risks, controls and treatments, third-party contracts and engagements, audits, workpapers and scopes, issues and their links, and compliance-automation frameworks. Use when the agent must register or review a risk, assess a vendor engagement, run an audit step, or raise and track an issue. Do NOT use for privacy assessments (onetrust-privacy-assessments) or data-subject requests (onetrust-dsar-incident-response).
