# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.3.7] - 2026-11-12

### Changed
- Every API operation is served as its own typed tool; the per-domain action-routed
  tools, their toggles and the generator that emitted them are removed. The tool
  count is 600: 596 operations, the raw request tool and three knowledge-graph
  ingest tools.
- Declare tool-use contracts, links, data locations and business roles
  (`connector_contracts.py`); ship an operator and five business-role agent
  prompts and eight skills that name every tool; root every ontology class in a
  core class.
- Require `scion-sdk>=0.9.0,<1.0.0`.

### Removed
- `onetrust_perform_risk_action_using_put`: the operation is deprecated upstream and
  its `{action}` path parameter selects among thirteen workflow states.
- The `action` query parameter of `onetrust_update_risk_using_put`.

## [1.3.6] - 2026-10-30

### Changed
- Require `scion-sdk>=0.6.4,<0.7.0`; `uv.lock` relocked.

## [0.1.0] - 2026-06-15

### Added
- Initial release: OneTrust API client + MCP server + A2A agent.
- 100% coverage of the OneTrust public API — 35 vendored OpenAPI specs,
  ~600 operations across 7 product areas — generated by
  `scripts/generate_from_openapi.py`.
- 36 action-routed MCP tools (one per domain) plus a `custom_api` escape hatch.
- OAuth2 bearer-token and client-credentials authentication, OIDC delegation,
  multi-region/multi-service host resolution, dual pagination (offset + cursor),
  and `429`/transient-error retry handling.
- Coverage keystone test asserting spec operations == client methods == MCP actions.
